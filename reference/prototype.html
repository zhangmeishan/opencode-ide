Agent-Driven Research Workflows
for Scientific Writing

OpenCode Research Group
November 2026

Abstract—We investigate an integrated scientific authoring workflow in which an autonomous coding assistant collaborates with a LaTeX editing environment, compilation tools, and iterative PDF validation.

1. Introduction

Recent progress in foundation models has enabled new approaches to scientific writing and software development. However, researchers still alternate between source editing, compilation and reading rendered output.

Our environment separates these activities into two persistent windows. A source editor supports code intelligence, while a result viewer presents the latest compiled artifact.

2. Method

We establish a modular bridge between an agent service and a standard development workbench. Extensions offer rich language support, diagnostics, compilation and references management.

L = Ltask + λ Lfeedback

3. Experiments

The prototype supports context-rich agent interaction, task execution and direct inspection of output files. Compilation errors can be passed to the assistant without abandoning the editor.
